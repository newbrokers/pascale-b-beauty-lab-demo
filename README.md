# Pascale B Beauty Lab — concept demo

Concept website built for outreach to **Pascale B Beauty Lab**, a beauty salon
in Limassol, Cyprus (Vasili Vrionidi 6). Their Google Business listing has a
5.0 rating from 68 reviews and no website — this is a first-draft concept to
show them what a real site could look like.

- Built from the salon's real Google Business photos, rating, address, and phone.
- Services list is a generic placeholder — swap in the real menu before sending.
- `index.html` is fully self-contained (images embedded as base64) — deploy as-is to Vercel, no build step needed.
